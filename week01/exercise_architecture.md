# Άσκηση εβδομάδας 1 – Το μηχάνημά μου

Τρέξτε `./sysinfo.sh | tee my_machine.txt` και συμπληρώστε τον πίνακα.

| Χαρακτηριστικό | Τιμή | Εντολή που το έδωσε |
|---|---|---|
| Αρχιτεκτονική (x86_64 / arm64) | | |
| Μοντέλο CPU | | |
| Sockets | | |
| Φυσικοί πυρήνες | | |
| Λογικά νήματα (SMT/Hyper-Threading) | | |
| Cache L1d / L2 / L3 (μέγεθος) | | |
| NUMA nodes | | |
| RAM | | |
| GPU (ναι/όχι, μοντέλο) | | |

Ερωτήσεις:
1. Σε ποια κατηγορία της ταξινόμησης Flynn ανήκει ο επεξεργαστής σας (και τι
   αλλάζει όταν λάβουμε υπόψη τις εντολές SIMD, π.χ. AVX/NEON);
2. Είναι το μηχάνημά σας UMA ή NUMA; Πώς το καταλάβατε;
3. Τρέξτε `./burn 20 &` τόσες φορές όσα τα λογικά νήματα σας και κοιτάξτε το
   `htop`. Τι παρατηρείτε όταν ξεκινήσετε περισσότερα από όσα νήματα έχετε;
4. (Bonus) Ανοίξτε το `lstopo` και αντιστοιχίστε την εικόνα με τα αποτελέσματα του `lscpu`.
